# 人脸识别登录系统（本地版）

一个跑在自己电脑上的轻量人脸识别登录实验项目。识别、存储全部在**本机完成**，人脸图像不上传。

---

> ## ⚠️ 用途声明与安全边界（请先读这段）
>
> **这是教学 / 实验项目，请勿用于真实的门禁、考勤或身份认证场景。**
>
> - **没有活体检测。** 用一张照片、或手机屏幕上的脸对着摄像头，**可能就能通过验证**。
>   它证明的是"画面里出现了一张相似的脸"，而不是"真人站在摄像头前"。
> - 相似度阈值默认 `0.50`，是经验值，**尚未用真实样本校准**（测误接受率需要他人样本）。
> - 登录接口会返回相似度数值 —— 这是**刻意为之**，便于校准阈值，**生产环境不应如此**。
> - 服务使用 Flask 开发服务器，只监听 `127.0.0.1`，**不要暴露到公网**。
>
> 如果你需要能抵御**呈现攻击**（presentation attack）的方案，本项目**不是**：
> 它缺少活体检测、深度伪造检测等必要环节。这里实现的是一套
> **口令认证基线 + 人脸作为辅助因子**的完整工程骨架，而不是一个安全的人脸认证产品。

---


## 怎么运行（一键启动）

**最省事：双击 `一键启动-无窗口.vbs`**

双击后不会弹出任何窗口，等 2–3 秒浏览器自动打开 <http://127.0.0.1:5000/>。
**不用了直接关掉网页就行**——约 5 秒后服务自动停止、摄像头自动释放，不需要额外操作。

**想看到运行日志：双击 `一键启动-有窗口.bat`**

会弹出一个命令行窗口，日志实时可见。**那个窗口就是服务本身，关掉窗口服务就停了。**

**全部脚本：**

| 文件 | 说明 |
|---|---|
| `一键启动-无窗口.vbs` | **推荐**。静默无窗口启动，自动开浏览器 |
| `一键启动-有窗口.bat` | 有窗口、日志实时可见；关窗即停，排错时用 |
| `停止服务.bat` | 强制停止服务（一般用不到——关掉网页会自动停） |
| `诊断.bat` | 检查环境并生成 `diagnose_result.txt` |

> - **关掉网页 ≈ 关掉软件**：约 5 秒后服务自行退出（宽限期内重新打开页面会取消退出，所以刷新不会误杀）。
> - 服务**已经在运行时**再双击启动器不会启动第二个副本，只会帮你把浏览器打开。
> - 启动失败会**弹窗说明原因**（不再默默闪退），详情同时写进 `launch_log.txt`。
> - Windows 默认隐藏文件扩展名，所以显示出来的文件名不带 `.vbs` / `.bat`——按名称区分即可。
>
> 完整的分步操作（注册、录入人脸、登录、出错怎么办）见 **[使用教程.md](使用教程.md)**。

## 页面上能做什么

| 区域 | 功能 |
|---|---|
| 左侧 | 摄像头实时画面，检测到人脸画绿框并显示置信度；显示当前阈值与密码哈希算法 |
| 登录状态 | 显示当前登录用户、已录入的人脸模板组数；录入人脸、退出登录、删除人脸数据（需密码确认） |
| 登录 | 「账号 + 人脸」1:1 验证，或「账号 + 密码」回退登录 |
| 注册新账号 | 用户名 3-32 位，密码至少 6 位；注册后自动登录 |
| 阈值校准 | 在线调整相似度阈值（0.20-0.95），改完立即生效 |
| 审计记录 | 本人最近的登录、录入、删除、阈值变更记录（含相似度与失败原因） |

## 登录策略（默认值，可用环境变量覆盖）

| 项 | 默认 | 环境变量 |
|---|---|---|
| 人脸相似度阈值 | 0.50 | `FACELOGIN_THRESHOLD`（也可在页面上改，改后落库） |
| 允许失败次数 | 3 | `FACELOGIN_MAX_FAILS` |
| 锁定时长 | 180 秒 | `FACELOGIN_LOCK_SECONDS` |
| 密码哈希 | Argon2id | 装不上 argon2-cffi 时自动退回标准库 scrypt |
| 会话 | 8 小时，HttpOnly + SameSite=Lax | — |
| 数据文件 | `data\faces.db` | `FACELOGIN_DATA`（改目录） |
| 模型目录 | `<项目根>\models` | `FACELOGIN_MODELS`（见下方「人脸模型」） |
| 关掉网页后自动退出 | **开启** | `FACELOGIN_AUTO_EXIT`（设 `0` 关闭该功能） |
| └ 退出宽限期 | 5 秒 | `FACELOGIN_EXIT_GRACE` |
| └ 无活动兜底超时 | 120 秒 | `FACELOGIN_EXIT_IDLE` |

- 密码错误或人脸不匹配都会累计失败次数，**连续 3 次锁定 3 分钟**；锁定期内密码和人脸两种方式都无法登录。
- 用户名不存在时也做一次等价的哈希运算，避免通过响应快慢猜出账号是否存在。
- 人脸登录是「**账号先行 + 1:1 比对**」，不需要遍历所有用户。

### 关掉网页就自动退出（释放摄像头）

页面每 2 秒轮询一次 `/api/state`，本身就是心跳；关闭或刷新页面时前端再通过 `sendBeacon`
发一次 `/api/bye`。收到后**先给 5 秒宽限期**，期间只要有新的页面请求进来就**取消退出**
（所以「刷新页面」不会被误判成「关闭」），宽限期过了才真正退出进程并释放摄像头。

| 情况 | 行为 |
|---|---|
| 关掉网页 / 关掉浏览器 | 约 5 秒后自动退出 |
| 刷新页面 | 不退出（宽限期内重新加载会取消） |
| 浏览器崩溃、来不及通知 | 120 秒无任何请求后自动退出（兜底） |
| 只启动、**从未打开过页面** | 永不自动退出（避免"启动完就自己没了"） |
| 想让它一直跑 | 启动前设 `FACELOGIN_AUTO_EXIT=0` |

## 数据存在哪里

SQLite 单文件：`data\faces.db`（首次运行自动创建）

| 表 | 存什么 |
|---|---|
| `users` | 用户名、**密码哈希**、失败计数、锁定截止时间、最后登录时间 |
| `face_templates` | 人脸**特征向量**（128 维 float32，512 字节 BLOB），每用户最多保留 8 组 |
| `login_events` | 审计事件：注册、密码/人脸登录、锁定、录入、删除、阈值变更 |
| `settings` | 会话签名密钥、当前阈值 |

**不保存原始人脸照片，也不保存摄像头视频。** 但特征向量本身仍是敏感生物特征信息，不要把这个文件随意复制给别人。

## 运行依赖

**平台：Windows**（摄像头使用 `cv2.CAP_DSHOW` 后端，且启动器是 `.bat` / `.vbs`）。
Linux / macOS 需要改动摄像头后端与启动脚本，目前未适配。

- Python 3.13（缺少 `.venv` 时启动脚本会自动创建并安装依赖）
- 依赖见 [`requirements.txt`](requirements.txt)：
  Flask 3.1.3 · NumPy 2.5.3 · opencv-python-headless 5.0.0.93 · argon2-cffi 25.1.0

### 从源码开始

```bash
git clone <仓库地址>
cd <仓库目录>

python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt

# 然后双击 一键启动-无窗口.vbs，或：
.venv\Scripts\python.exe app\run.py
```

模型已随仓库提供，**不需要额外下载**；若确实缺失，运行 `python tools\download_models.py`。

### 关于中文路径（曾经踩过的坑）

**OpenCV 无法从非 ASCII 路径读取 ONNX 模型。** 这不是猜测，是本项目实测的：

| 尝试 | 结果 |
|---|---|
| 把含中文的路径直接交给 `cv2.FaceDetectorYN.create()` | ❌ `Can't read ONNX file` |
| 改传内存 bytes（C++ 侧有 buffer 重载） | ❌ Python 绑定不接受，进程**段错误**退出 |
| Windows 8.3 短路径（`GetShortPathNameW`） | ❌ 数据卷默认不生成短名，返回的仍是中文路径 |
| 把模型镜像到纯 ASCII 目录再加载 | ✅ 可行 |

所以 `app/model_paths.py` 会在路径含非 ASCII 字符时，自动把模型复制到一个
纯 ASCII 的缓存目录（`%LOCALAPPDATA%\FaceLogin\models`，退回临时目录），
校验大小与时间戳后复用，**你不需要做任何配置**。

> 这也解释了为什么项目里**不写死任何绝对路径** —— 每个人把仓库 clone 到哪里都不一样。

需要重新下载模型时（比如 clone 时用了 sparse-checkout）：

```bash
python tools/download_models.py            # 走 LFS 直链 + SHA-256 校验
python tools/download_models.py --no-proxy # 系统代理失效时
```

## 当前限制（重要）

- **没有活体检测**：照片或手机屏幕上的脸可能骗过它。密码回退不能替代这一点。
- 登录接口会返回相似度数值，这是**为了校准阈值**；正式使用时不应把比对细节返回给客户端。
- 服务用的是 Flask 开发服务器，适合本机实验，不要直接暴露到公网。
- 单机单用户设计：没有角色/权限模型，登录后能看到所有用户列表。
- 用户名与密码没有找回机制；忘记密码只能删掉 `data\faces.db` 重来。
- 阈值 0.50 仍是默认值，**尚未用真实样本校准**（需要他人样本才能测误接受率）。

## 排错

**双击启动后弹窗报错？** 弹窗里写了原因（启动器会把错误也写进 `launch_log.txt`）。

**双击闪退？** 运行 `诊断.bat`，把 `diagnose_result.txt` 内容发出来。

**弹窗说找不到 `app\run.py`？** 启动脚本路径拼接问题，已修复；若仍出现，请确认脚本和 `app` 文件夹在同一目录下。

**弹窗说摄像头没打开？** 微信 / 腾讯会议 / 相机等程序占用了摄像头，关掉它们再重新启动服务。

**浏览器没自动打开？** 手动访问 <http://127.0.0.1:5000/>。

**提示端口被占用？** 先运行 `停止服务.bat`。

**弹窗说找不到模型？** 检查项目下的 `models\` 里两个 `.onnx` 是否都在；
缺失就运行 `python tools\download_models.py` 重新下载。

**脚本输出乱码或报错？** 查看 `launch_log.txt`。

## 脚本编写约定（改脚本时注意）

- `.bat` / `.vbs` 必须使用 **CRLF 换行**，否则 `cmd` 会解析错乱、窗口瞬间闪退。
- 路径一律用 `%~dp0`（bat）或 `FileSystemObject.BuildPath`（vbs）拼接，**不要手写 `\`**，漏一个斜杠就会变成不存在的路径。
- 脚本内容保持**纯 ASCII**，避免中文编码在 GBK 控制台下出错。

> `.gitattributes` 已把 `*.bat` / `*.vbs` 锁定为 `eol=crlf`，避免 clone 之后
> 换行符被规范化成 LF、又踩回同一个坑。

## 已知限制与后续计划

已在做的方向（按优先级）：

- [ ] **活体检测** —— 目前最大的安全短板。受模型能力限制，YuNet 只输出人脸框与 5 个关键点
      （不含眼睑），**无法做眨眼检测**；可行的零额外模型方案是**随机动作挑战**（用 5 点估计头部姿态）。
- [ ] **阈值校准** —— 用真人样本测误接受率 / 误拒绝率，把 0.50 换成有依据的值。
      目前只有单人数据（同人相似度 0.93 左右，他人 0.21 左右）。
- [ ] **界面重构** —— 把内嵌在 `server.py` 里的页面拆成独立文件，改善观感与可维护性。
- [ ] **打包** —— 做成免安装的可执行文件，省掉 `.venv` 这一步。
